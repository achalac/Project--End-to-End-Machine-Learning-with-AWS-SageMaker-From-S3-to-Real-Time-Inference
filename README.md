# End-to-End-Machine-Learning-with-AWS-SageMaker-From-S3-to-Real-Time-Inference
Predicting Term Deposit Subscriptions Using Machine Learning in the Cloud

AWS SageMaker XGBoost Project: End-to-End ML with Real-Time Deployment
This project demonstrates a full machine learning pipeline using Amazon SageMaker for a binary classification task on a real-world dataset. It includes data preprocessing, training using the built-in XGBoost container, deploying a real-time inference endpoint, and evaluating the model — all using Python and AWS tools.

What’s Inside
✅ Data preprocessing and feature engineering using pandas and numpy

✅ Uploading train/test datasets to S3

✅ Training an XGBoost model using SageMaker’s built-in algorithm

✅ Deploying the model to a real-time SageMaker endpoint

✅ Performing predictions and evaluating performance (confusion matrix + accuracy)

✅ Cleaning up AWS resources to reduce cost


Technologies Used
AWS SageMaker

Amazon S3

XGBoost (built-in container)

Python (boto3, pandas, numpy, sagemaker SDK)

Jupyter Notebook
